# יועץ השקעות נדל"ן חכם

> כלי אנליטיקה מבוסס ML+GIS המסייע למשקיעים לאתר, לסנן ולבדוק עסקאות נדל"ן — מותאם אישית לפרופיל ההשקעה של כל משתמש.

---

## הבעיה שאנחנו פותרים

שוק הדיור מושפע מפרמטרים רבים ומשתנים — ביקוש והיצע, מצב השוק, אירועים פוליטיים וטבעיים. משקיע נדל"ן נדרש לנתח את כולם, לאתר עסקה משתלמת ולהחליט האם להיכנס אליה, לרוב ללא כלים מתאימים.

הכלי מרכז את המידע במקום אחד ומחזיר המלצות מדורגות בשלוש רמות זום: **אזור ← נכסים ← עסקה בודדת**.

**קהל יעד:**
- משקיעים פרטיים המעוניינים להיכנס לשוק הנדל"ן
- משקיעים מנוסים המחפשים את העסקה הבאה שלהם
- אנשי מקצוע: מתווכים ושמאים

## ארכיטקטורה

### מודל ML
- **אלגוריתם:** XGBoost Regressor
- **Target:** `dealAmount` (מחיר עסקה בשקלים)
- **Features:** שטח, חדרים, קומה, יישוב (encoded), שכונה (encoded), רחוב (target-encoded), קואורדינטות, מדד סוציו-אקונומי, שנה/חודש עסקה, קרבה ל-POI (בתי ספר, תחנות רכבת, פארקים ועוד)
- **ביצועים:** R² = 0.741 · RMSE ≈ 607,000 ₪ (≈ 19% מהמחיר הממוצע)

### ציון כדאיות
נוסחה אחידה בכל שלושת המצבים:
```
ציון = clip(50 + gap% × 1.5, 0, 100)
```
- gap = 0% (מחיר שוק הוגן) → ציון 50
- gap = +20% (מתומחר בחסר ב-20%) → ציון 80
- gap = −20% (יקר מהשוק ב-20%) → ציון 20

## מבנה האפליקציה — 5 טאבים

### 👤 פרופיל משקיע
הגדרת פרופיל אחד המשותף לכל המצבים:
- **תקציב מקסימום** — מגביל את האזורים / העסקאות המוצגות
- **מטרת השקעה** — תשואה שוטפת / עליית ערך
- **אופק השקעה** — קצר (1–3 שנה) / ארוך (5+ שנה)
- **תשואה שנתית מינימלית (%)** — סינון אזורים שאינם עונים על הדרישה
- **רמת סיכון** — שוק מבוסס / מתפתח
- **מינימום עסקאות ביישוב** — מבטיח נתונים מספיקים

### 🗺️ מצב א׳ — המלצת אזורים
- טבלת אזורים מדורגת לפי פרופיל המשקיע (ציון כדאיות, תשואה חזויה, מחיר ממוצע)
- **מפת חום** של ישראל (density mapbox) — ויזואליזציה גאוגרפית של אזורי ההשקעה הטובים ביותר
- ציון כדאיות מחושב לפי שילוב משוקלל של: פער מחיר, טרנד עלייה, נזילות (מספר עסקאות)

### 🏘️ מצב ב׳ — דירוג נכסים ביישוב
- בחירת יישוב ספציפי
- פילטרים: שטח, מספר חדרים, שנת עסקה
- טבלה מדורגת עם `ProgressColumn` לציון הכדאיות

### 🔍 מצב ג׳ — בדיקת עסקה בודדת
- הזנת פרטי נכס: יישוב, שטח, חדרים, קומה, מחיר מבוקש
- המודל מחשב מחיר שוק הוגן
- פלט: ציון כדאיות, פער מהשוק (%), פסיקה (כדאי / גבולי / לא כדאי)
- השוואה לעסקאות דומות ביישוב

### 📖 הסברים
- תיאור המתודולוגיה, מגבלות המודל, ומקורות הנתונים

## 5 סיפורי משתמש

**1. משקיע מתחיל — הכוונה לאזור (מצב א׳)**
כמשקיע שנכנס לשוק לראשונה, אני רוצה להגדיר פרופיל השקעה ולקבל מפה של אזורים מומלצים עם ציון כדאיות, כדי לצמצם את מרחב החיפוש לפני שאבחן נכסים ספציפיים.

**2. משקיע מנוסה — חיפוש עסקאות באזור (מצב ב׳)**
כמשקיע שזיהה אזור מעניין, אני רוצה רשימה מדורגת של נכסים לפי התאמה לפרופיל שלי, כדי שלא אצטרך לסרוק ידנית מאות מודעות.

**3. משקיע — בדיקת עסקה ספציפית (מצב ג׳)**
כמשקיע שמצא נכס, אני רוצה להזין פרטים ומחיר ולקבל ציון כדאיות והשוואה לשוק — כדי להחליט האם להתקדם לבדיקת נאותות.

**4. משקיע — השוואה בין שתי עסקאות (מצב ג׳ פעמיים)**
כמשקיע שמתלבט בין שני נכסים, אני רוצה להריץ בדיקת כדאיות על שניהם ולקבל השוואה ישירה.

**5. מתווך — הצגת ניתוח מקצועי ללקוח (מצב ג׳)**
כמתווך, אני רוצה להפיק ניתוח כדאיות מפורט לנכס ספציפי, כדי לבסס את המלצתי על נתונים.
